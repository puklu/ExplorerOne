Detailed Description

STM32F3-specific RCC (Reset and Clock Control) implementation.

This class provides concrete implementations for the IRcc interface for STM32F3 series MCUs. It manages system clocks, peripheral clocks, PLL setup, AHB/APB prescalers, and enables/disables specific peripheral clocks.
